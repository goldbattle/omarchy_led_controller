# Extras

**Optional. Most people don't need anything here.** The plugin works with everything OpenRGB
detects. Each extra adds support for hardware OpenRGB can't reach yet, needs root to install,
and is only worth it if the tested hardware table in the [README](../README.md#tested-hardware)
sends you here.

| Extra | For | Setup |
|---|---|---|
| `asus-aura/` | ASUS boards with Aura behind the Super I/O (e.g. PRIME X299-A) | [docs/asus-aura.md](../docs/asus-aura.md) |
